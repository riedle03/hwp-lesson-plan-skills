# hwp-lesson-plan-skills

클로드 코드(Claude Code)로 **한글 파일(hwp·hwpx) 양식을 그대로 둔 채 칸만 채우는** 스킬 두 개입니다.
빈 수업지도안 양식을 폴더에 넣고 한 줄로 맡기면, 에이전트가 양식 구조를 읽고 내용을 쓴 뒤 같은 한글 파일로 저장합니다.

현직 국어교사 · 『요즘 교사를 위한 웹앱 만들기』 공저자가 수업지도안 작업에 쓰는 스킬을 그대로 공개합니다.
블로그 글(사용 장면 영상): https://blog.naver.com/edutech-lab

## 들어 있는 것

| 스킬 | 하는 일 |
|---|---|
| `hwp-template-fill` | 오케스트레이터. 양식 파일 형식을 보고 엔진을 고른 뒤, 양식 분석 → 내용 작성 → 되채우기 → 검증을 끝까지 돈다 |
| `hwpx-format-clone` | `.hwpx` 엔진. 양식 파일을 복제해 본문 XML만 바꾼다. 표·테두리·글꼴을 새로 만들지 않아 서식이 그대로 남는다 |

`.hwp`(구형 바이너리) 양식은 [NomaDamas/k-skill](https://github.com/NomaDamas/k-skill) 저장소의 `rhwp-edit` 스킬이 엔진입니다. 이 저장소에는 넣지 않았으니 그쪽에서 설치하세요(MIT).

## 설치

1. 클로드 코드를 설치합니다.
2. 이 저장소의 `skills/` 아래 두 폴더를 `~/.claude/skills/`(Windows: `C:\Users\<이름>\.claude\skills\`)에 복사합니다.
   클로드 코드에게 이렇게 시켜도 됩니다.
   ```
   https://github.com/riedle03/hwp-lesson-plan-skills 의 skills 폴더에 있는 스킬 두 개를 내 ~/.claude/skills 에 설치해 줘.
   ```
3. `.hwp` 양식도 쓰려면 `rhwp-edit` 를 설치합니다.
   ```
   https://github.com/NomaDamas/k-skill 의 rhwp-edit 스킬을 내 ~/.claude/skills 에 설치해 줘.
   ```
4. 검증 단계에서 `npx k-skill-rhwp`(Node.js 18 이상)와 Python을 씁니다. 없으면 클로드 코드가 설치를 안내합니다.

## 쓰는 법

빈 양식(.hwpx 또는 .hwp)을 한 폴더에 넣고, 그 폴더에서 클로드 코드를 열어 이렇게 입력합니다.
아래는 사용 장면 영상에서 실제로 입력한 문장입니다.

```
폴더의 교과-독서 지도안 양식으로, 고등학교 1학년 IT 분야 학생들이 반드시 읽어야 할 창업 관련 책을 한 권 골라 진로 독서 프로젝트 수업 지도안을 hwpx로 작성해 줘. 질문하지 말고 스스로 판단해서 끝까지 진행해 줘.
```

## 알아 둘 것

- 결과 파일은 반드시 한글에서 열어 확인하세요. **쪽 넘김 위치**는 도구로 검증하지 못합니다.
- 같은 문장으로 다시 돌리면 고르는 책·문장이 달라질 수 있습니다.
- `.hwp` 양식은 셀 안 서식(굵게·글머리표) 제어가 약합니다. 서식이 많은 양식은 한글에서 `.hwpx`로 저장해 쓰는 편이 안정적입니다.
- 학생 이름·성적 같은 개인정보가 든 파일은 넣지 마세요.
